Click-to-Move & Click-to-Attack

MOBA-style input: click ground to move, click enemies to auto attack. Movement is replicated to the server.

  • Raycast under cursor to distinguish enemies from ground using gameplay tags
  • Enemy clicks activate BP_AutoAttack through GAS
  • Ground clicks spawn click VFX and request nav mesh movement
  • C++ handles local HUD, camera setup, and server-authoritative movement RPC

Gameplay Ability System Architecture

GAS lives on PlayerState for multiplayer-safe ability ownership. Attributes replicate and clamp on change.

  • PlayerState owns the ASC and grants Auto Attack + Flash at startup
  • Health, mana, regen, and attack damage defined in a custom AttributeSet
  • HybridGasBlueprintLibrary bridges Blueprint projectiles to C++ GAS helpers
  • Projectiles apply GE_Damage through outgoing effect specs
MyPlayerState.cpp C++ 
void AMyPlayerState::InitializeGAS(APawn* AvatarActor)
{
    AbilitySystemComponent->InitAbilityActorInfo(this, AvatarActor);

    if (!HasAuthority()) return;

    if (!bDefaultAttributesApplied)
        ApplyStartupGameplayEffects();

    if (!bStartupAbilitiesGranted)
        GrantStartupAbilities();
}

void UMyAttributeSet::PostGameplayEffectExecute(
    const FGameplayEffectModCallbackData& Data)
{
    if (Data.EvaluatedData.Attribute == GetHealthAttribute())
        SetHealth(FMath::Clamp(GetHealth(), 0.f, GetMaxHealth()));
}

Flash Ability – Cursor-Targeted Dash

Signature mobility ability built as a GAS gameplay ability with mouse-to-world targeting.

  • Traces mouse cursor to world position on the horizontal plane
  • Calculates dash direction and clamps range to 400 units
  • Teleports character, updates rotation, and stops movement on arrival
  • Plays teleport sound and Niagara VFX on ability commit
  • Granted at startup from PlayerState alongside Auto Attack

void AMyPlayerState::GrantStartupAbilities()
{
    for (const TSubclassOf<UGameplayAbility>& AbilityClass : StartupAbilities)
    {
        if (AbilityClass)
        {
            AbilitySystemComponent->GiveAbility(
                FGameplayAbilitySpec(AbilityClass, 1, INDEX_NONE, this));
        }
    }
    bStartupAbilitiesGranted = true;
}

  • C++ helper configures homing target, speed, and initial velocity after spawn

HybridGasBlueprintLibrary.cpp C++ 
void UHybridGasBlueprintLibrary::InitializeProjectileHoming(
    AActor* Projectile, AActor* HomingTarget, float Speed, bool bUseHoming)
{
    SetActorObjectProperty(Projectile, "HomingTarget", HomingTarget);
    SetActorBoolProperty(Projectile, "UseHoming", bUseHoming);
    SetActorFloatProperty(Projectile, "HomingSpeed", Speed);

    const FVector Direction =
        (HomingTarget->GetActorLocation() - Projectile->GetActorLocation())
        .GetSafeNormal();

    if (auto* Move = Projectile->FindComponentByClass<UProjectileMovementComponent>())
        Move->Velocity = Direction * Speed;
}

  • Cooldown decorator prevents attack spam every 2 seconds

NPCUnit.cpp C++ 
void ANPCUnit::ShootAtTarget(AActor* Target)
{
    if (!HasAuthority() || !Target || !ProjectileClass) return;

    const FVector Direction =
        (Target->GetActorLocation() - GetActorLocation()).GetSafeNormal();

    AActor* Projectile = GetWorld()->SpawnActor<AActor>(
        ProjectileClass, GetActorLocation(), Direction.Rotation(), SpawnParams);

    UHybridGasBlueprintLibrary::InitializeProjectileHoming(
        Projectile, Target, ProjectileSpeed);
}

TopDownPaperCharacter.cpp C++ 
void ATopDownPaperCharacter::PrepareForRangedAttack(
    const FVector& TargetWorldLocation)
{
    bLockSpriteFacing = true;
    bIsMoving = false;
    GetCharacterMovement()->StopMovementImmediately();

    FVector AimDirection = TargetWorldLocation - GetActorLocation();
    AimDirection.Z = 0.f;

    if (!AimDirection.IsNearlyZero())
        DirectionIndex = static_cast<uint8>(DirectionFromVelocity(AimDirection));

    ApplySpriteAnimation();
}

UAbilitySystemComponent* ATopDownPaperCharacter::GetAbilitySystemComponent() const
{
    if (const APlayerState* PS = GetPlayerState())
        return PS->FindComponentByClass<UAbilitySystemComponent>();
    return nullptr;
}
